# Screenshot gallery

The README shows the dark set. This page keeps both appearances side by side and
adds close-ups of features that are unusual in a native, agent-first workspace.

These retained captures were made from a source build over a desktop background so the
translucent chrome is visible. They use a controlled local `Dunlin project`
fixture and a disposable demo session with the OpenCode ACP harness and the free
**Iceman Free** model. Images are 1800×1076.

They were not recaptured during the 2026-11-09 documentation rebuild. UI details
and model availability may differ from the current source; screenshots are
illustrations, not fresh acceptance evidence.

The first three close-ups are the parts that are hardest to find combined in one
native app: a visual Markdown editor that is still a real editor, a full Git
workbench with graph and diffs, and credentials that agents can use without ever
receiving the value. The permission center shows the other side of the same
contract: what an agent may do automatically, what remains enforced by the
harness, and what macOS still controls.
